# 📦 Module: 03-dnf-package-control

🌀 **Advanced DNF usage, rollback, locking, and AppStream management for AlmaLinux 9.6**  
This module teaches you to master `dnf` beyond `install` and `update`, and protect your packages like a pro.

---

## 🧱 Goals

| Feature             | Description |
|---------------------|-------------|
| 🔄 Rollback         | Use DNF history safely to undo package changes |
| 🔒 Locking          | Prevent package upgrades for critical services |
| 🧩 AppStreams       | Enable/disable specific streams (e.g. PHP, MariaDB) |
| 📦 Group Mgmt       | Manage group installs, group info, group remove |
| 📜 Repo Control     | View, enable/disable, prioritize repositories |

---

## 🚀 Scripts (Planned)

| Script File              | Purpose |
|--------------------------|---------|
| `dnf-rollback.sh`        | View and rollback transactions safely |
| `dnf-lockdown.sh`        | Lock packages to current version (dnf versionlock) |
| `dnf-appstreams.sh`      | Manage AppStream modules (list, enable, reset) |
| `dnf-groups.sh`          | Handle group installs like `@server`, `@security-tools` |
| `dnf-repo-control.sh`    | Control enabled repos and priorities |
